# 🌱 Садовый симулятор

Пиксельный кликер-садовод для **Яндекс Игр**. Тапай по грядкам: сажай → поливай → собирай урожай. Прокачивай сад, лови рыбу, собирай аквариум, открывай питомцев и гибриды, уходи в престиж.

## ▶️ Играть

Откройте `index.html` — игра полностью автономна (один файл, без внешних зависимостей, кроме Yandex Games SDK).

## 🎮 Возможности

- 15 растений, включая крафтовые гибриды и золотые семена
- Погода, сезоны, день/ночь, случайные события и боссы
- Пруд с рыбалкой (с 5 уровня) и аквариум (+1% к монетам за каждый вид)
- 6 питомцев-помощников, система домика с оффлайн-доходом
- Квесты, NPC-торговец, ежедневные бонусы, стрики
- Престиж (с 30 уровня), магазин за звёзды, скины сада
- Достижения, рекорды, статистика
- ☁️ Облачные сохранения и 🏆 лидерборды через Yandex Games SDK
- Rewarded-реклама: бонус x2 и буст роста x2

## 📁 Структура

```
index.html     — вся игра (HTML+CSS+JS в одном файле)
privacy.html   — политика конфиденциальности (для модерации Яндекс Игр)
assets/        — иконка, обложка, скриншоты для публикации
```

## 🚀 Публикация на Яндекс Играх

1. Заполните свои данные в `privacy.html` и задеплойте репозиторий на GitHub Pages — ссылку на политику укажите в игре и в черновике.
2. Соберите ZIP с `index.html` в корне.
3. В консоли `yandex.ru/dev/games` создайте лидерборд `coins_total`, включите облачные сохранения и монетизацию.

Подробный чек-лист — в файле `Инструкция_публикации_Яндекс_Игры.md`.
